# Behavior entry points

These internal modules connect the styled wrappers to the single [Kobalte subset](../../vendor/kobalte/README.md). The shared modal helper uses external Solid Primitives. The hidden-select entry supports native form values for Select and Combobox.

Applications import the [styled controls](../../components/README.md) from public package paths. Keep CSS in the [shared styles](../../styles/README.md) and keep application rules in the consumer.
